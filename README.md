# web-application
QR tickect authentication and wallet system for public bus transports
The role of public transport in sustainable urban mobility, yet bus ticketing sys-
tems often rely on there is much of manual verification and fragmented digital plat-
forms. This paper proposes QR-based ticket authentication and wallet system.A
system that mechanizes the creation and verification of tickets, as well as data ma-
nipulation for public bus networks, after which the system will generate a unique QR
code containing passenger and travel information, thus, allowing the end-to-end se-
cure and allow contactless boarding, decreases frauds, and requires less human inter-
vention.Coded with integrated GPS tracking, This allows users to track the presence
of buses and arrival in real time, thus, increasing the level of transparency. AI and
based on it, user profiling and personalization, built on cloud-supported architecture
with a web-based front end and a PHP/Python backend connected with MySQL Re-
liability. Experimental results validate the efficiency and verification speed of the
system, as well as a better user experience compared to conventional ticketing sys-
tems. The proposed solution provides a one-stop, integrated solutions for secure, and
intelligent framework that advances smart public transport services.
Keywords: QR Code, Ticket Authentication, Digital Wallet, Public Transporta-
tion, Smart Mobility, GPS Tracking, Secure Verification System.
